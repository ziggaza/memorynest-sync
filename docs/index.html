Meet Memory Mapper

Smart event folders that think ahead.

Standard organizers sort by date. Memory Mapper sorts by meaning. Create named event rules — "Japan Trip 2024", "Mom's Birthday", "Summer Camp" — with a date range and optional device filter. When MemoryNest Sync runs, matching files land in your event folder automatically, not buried inside a generic date folder.

  • 📅Visual date picker — set start and end dates without typing
  • 📱Device filter — target a specific camera or apply to all devices
  • 🏆Priority matching — rules are checked in order; first match wins
  • ✏️Inline editing — rename or adjust any rule without leaving the screen
  • 📁Everything else falls back to your standard device / date structure

Meet Name Mapper

Give every file a name that actually means something.

Raw camera filenames like DSC_4821.jpg tell you nothing. Name Mapper uses EXIF tokens to rename files into clean, meaningful names — automatically, on every run. Pick a preset or build your own pattern from 14 tokens.

{date} {year} {month} {day} {time} {device} {make} {model} {category} {seq} {hour} {minute} {second} {original}
  • 🎛️7 built-in presets — ready to use in one click
  • 👁️Live preview — see exactly how files will be renamed before running
  • 🔢Smart sequence counter — {seq} resets per run, zero-pad width adjustable
  • 🛡️Duplicates stay original — renamed files never overwrite each other
  • 🔘Off by default — enable only when you want it, no surprises

Three steps to an organized library

No technical knowledge required.

1

Choose source & destination

Add one or more source folders from any drive or SD card — or simply drag & drop them into the app. Then pick a destination folder. You stay in full control of where everything goes.

2

Preview with Dry Run

See exactly which files move where, how many duplicates are found, and what the final structure looks like — file by file. Nothing happens until you say so.

3

Sit back & let it organize

Confirm and walk away. MemoryNest handles everything — skipping duplicates, logging every action, resuming if interrupted.

Safe by design — at every step

Your memories are irreplaceable. MemoryNest Sync is built around the principle of never losing a single file.

🛡️

Dry Run mode — ON by default

Every session starts in simulation mode. The full activity log shows exactly what would happen — file by file — before anything moves. Uncheck when you're ready.

📋

Copy or Move — your choice

Choose Copy to keep originals untouched while building a clean organized copy. Choose Move when disk space is tight. A confirmation dialog always appears before any real action.

🔒

100% offline — your files stay yours

No internet connection required. No account, no cloud sync, no telemetry. Your photos never leave your machine — ever.

♻️

Duplicates quarantined, never deleted

Duplicate files are moved to a Duplicates/ folder — not deleted. Review them yourself before deciding what to keep.
